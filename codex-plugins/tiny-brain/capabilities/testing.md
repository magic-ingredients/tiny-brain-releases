# Testing Review

## Description

Test quality analysis covering assertion quality, flaky test detection, test organisation, mock discipline, and test strategy. Evaluates whether existing tests are reliable, well-structured, and behaviour-driven. Does NOT check coverage — that is handled by the coverage-review capability.

## Detect

- Built-in capability (always available when plugin is installed)
