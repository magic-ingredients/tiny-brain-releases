# Codex hooks

The bundled `hooks.json` starts the Tiny Brain dashboard for new and resumed
Codex sessions. Codex requires a one-time hash-based trust review for this
command; open `/hooks` and trust the Tiny Brain hook after installing or
updating the plugin.

`tiny-brain init` separately configures Tiny Brain's portable Git hooks in each
repository, so commit enforcement works for every supported client.
